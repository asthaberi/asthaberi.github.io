    Featured · IIT Madras Deep Learning & GenAI diploma · Kaggle

    Smart MCQ Solver

    A model that picks the correct answer to multiple-choice questions. I fine-tuned DeBERTa-v3-small and RoBERTa-base with LoRA through Hugging Face's AutoModelForMultipleChoice, then deployed the final model to the Hugging Face Hub with a Streamlit front end.

    The most important result was a bug in the evaluation. Random train/validation splits put near-duplicate prompts on both sides, so validation scores were inflated. After I switched to grouped splits, the leakage went to zero, and the model choice reversed: a single RoBERTa-base beat the ensembles that had looked better before.

    63.1%prompt-core overlap between train and validation on random splits
    0%overlap after switching to grouped splits
    1 modelRoBERTa-base alone chosen over ensembles once leakage was removed

    RAG from first principles

    A retrieval pipeline written without libraries, with self-grading tests at each step: tokenize, chunk with overlap, build a vocabulary, embed as bag-of-words vectors, rank by cosine similarity, retrieve top-k and assemble the prompt. The search box at the top of this page runs the same steps.
